# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Changed

- **Rebrand:** Private Student Attendance (PSA) is now **Aurora** — zero-knowledge attendance on Midnight.
- **Redesign:** `attendance-ui` rebuilt on the new **Atmospheric Glass** design system (`design.md`) — aurora gradient
  canvas, frosted glass surfaces, Inter type scale, reusable component primitives, toasts, skeletons, empty/error
  states, mobile bottom navigation, and reduced-motion support.
- New brand mark, SVG favicon, page metadata and Open Graph tags.

### Removed

- Unreferenced legacy brand assets (`attendance-ui/public/icon.png`, `logo-render.png`, `midnight-logo.png`).
